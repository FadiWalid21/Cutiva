# دليل وصفات المنتجات — شرح كامل للمبتدئين

**الصفحة في البرنامج:** وصفات المنتجات (`/product-templates`)  
**الجمهور:** أي شخص يريد فهم كل حقل وتأثيره على المقاسات قبل استخدام الوصفة في المشروع.  
**اللغة:** عربي.

---

## 1. مقدمة: ما هي «وصفة المنتج»؟

تخيّل إن عندك شباك بعرض وارتفاع مختلفين كل مرة (مثلاً 100×120 سم أو 150×200 سم).  
بدل ما تحسب يدويًا طول كل قطعة ألومنيوم في كل مرة، تعرّف **وصفة مرة واحدة**:

- الشباك من أي قطع يتكون؟ (إطار علوي، سفلي، قائم، ضلفة…)
- طول كل قطعة كيف يُحسب من العرض والارتفاع؟
- الزجاج بأي مقاس؟
- الإكسسوارات بكم قطعة؟

بعدها في المشروع: تدخل مقاس العميل → البرنامج يطبّق الوصفة → يطلع أطوال القطع المطلوبة للقص والشراء.

```
الوصفة (قواعد عامة)  +  مقاس العميل (عرض × ارتفاع)  =  قائمة أطوال جاهزة
```

**مهم:** الأرقام في الوصفات المبدوءة (Seed) تجريبية. عدّلها حسب مقاسات ورشتك قبل الاعتماد.

---

## 2. خريطة الصفحة من اليمين لليسار (أو العكس حسب اللغة)

1. **قائمة أنواع المنتجات** — باب، شباك، ثم الموديلات (سحاب، مفصلي، قلاب…).
2. **بطاقة الموديل** — اسم، عدد الضلف، التداخل، نشط.
3. **جرّب المقاس** — معاينة سريعة بالأرقام قبل ما تدخل مشروع.
4. **أطوال القطع** — كل قطعة ألومنيوم ومعادلتها.
5. **فتحات الزجاج** — مقاس الزجاج.
6. **الإكسسوارات** — مقابض، عجلات… وقواعد الكمية.

اختر موديلًا من القائمة أولًا؛ بدون اختيار يظهر: «اختر موديلًا لتعديل أطوال القطع».

---

## 3. قسم الموديل (رأس الوصفة)

| الحقل | ماذا يعني؟ | تأثيره |
|--------|------------|--------|
| **الاسم** | اسم يظهر لك في القائمة والمشروع | تنظيم فقط؛ لا يغيّر الحساب |
| **عدد الضلف** | كم ضلفة في الوحدة (1، 2، 3…) | يدخل في حساب «تقسيم عرض الضلفة» وفي كمية إكسسوار «لكل ضلفة» |
| **التداخل (سم)** | مقدار التراكب بين الضلف (خصوصًا السحاب) | يُضاف للعرض الفعّال عند تفعيل تقسيم الضلفة |
| **نشط** | هل الموديل متاح للاستخدام في المشاريع؟ | لو مطفي، عادة ما يُختار في العمل اليومي |

بعد التعديل اضغط **حفظ** في بطاقة الموديل.  
**ملاحظة معاينة:** «جرّب المقاس» يستخدم القيم **المحفوظة** لعدد الضلف والتداخل، مش المسودة غير المحفوظة.

### رسم: عرض كامل مقابل عرض ضلفة

```
شباك سحاب بعدد ضلفتين = 2، عرض كلي W، تداخل O:

┌────────────── W (العرض الكلي) ──────────────┐
│┌──── ضلفة 1 ────┐┌──── ضلفة 2 ────┐│
││                ││← O تداخل →│                ││
│└────────────────┘└────────────────┘│
└────────────────────────────────────────────┘

العرض الفعّال لقطعة مقسّمة = (W ÷ 2) + O
```

## 4. جرّب المقاس (المعاينة الحية)

| الحقل | الافتراضي الشائع | الغرض |
|--------|------------------|--------|
| **عرض تجريبي (سم)** | 100 | تعرض النتيجة كأن العميل طلب هذا العرض |
| **ارتفاع تجريبي (سم)** | 120 | نفس الفكرة للارتفاع |

تحت الحقول تظهر قائمة: اسم القطعة → الكمية × الطول بالسم.

هذه المعاينة **للألومنيوم فقط** (لا تعرض الزجاج هنا).  
غيّر العرض/الارتفاع فورًا لترى الفرق؛ عدّل معادلة القطعة واحفظها ثم راجع المعاينة.

## 5. أطوال القطع — القلب الحسابي

كل بطاقة = قطعة واحدة (مثلاً Frame top، Sash stile).

### 5.1 المعادلة الأساسية (احفظها)

النظام يحسب داخليًا بالمليمتر (مم)، والواجهة تعرض كثيرًا بالسنتيمتر (سم).  
10 مم = 1 سم.

```
الطول (مم) =
    (عامل العرض × العرض الفعّال)
  + (عامل الارتفاع × الارتفاع)
  + التعديل (مم)
```

**العرض الفعّال:**

- لو «تقسيم عرض الضلفة» **مطفّى**: العرض الفعّال = عرض الفتحة كاملًا.
- لو **مفعّل**: العرض الفعّال = (العرض ÷ عدد الضلف) + التداخل.

ارتفاع القطعة دائمًا من **الارتفاع الكامل**؛ التقسيم لا يغيّر الارتفاع.

### 5.2 الجملة البسيطة (بدون فتح «متقدم»)

لما القطعة بسيطة (إما من العرض فقط أو من الارتفاع فقط)، الواجهة تعرض:

```
الطول = [العرض أو الارتفاع] [زائد أو ناقص] [N] سم ، الكمية [N]
```

| المدخل | المعنى | مثال التأثير |
|--------|--------|---------------|
| **اسم القطعة** | اسم يظهر في القوائم والتقارير | «إطار علوي» بدل placeholder |
| **العرض / الارتفاع** | المحور الأساسي للطول | علوي/سفلي غالبًا من العرض؛ قائم الضلفة من الارتفاع |
| **زائد / ناقص** | هل نضيف أو نخصم من المحور؟ | ناقص 4 سم = خلوص أو تداخل مع الإطار |
| **الرقم N (سم)** | مقدار الزيادة أو النقصان | 0 = نفس المقاس؛ 4 = أقصر بـ 4 سم |
| **الكمية** | كم قطعة من هذا الطول لكل وحدة منتج | قائم الضلفة غالبًا 2 |
| **ألومنيوم افتراضي** | بروفايل السوق الافتراضي لهذه القطعة | يسهّل الحساب والشراء لاحقًا |
| **+ إضافة جديد** | إنشاء بروفايل من هنا | يربط القطعة بخامة جديدة |

#### ربط الجملة البسيطة بالعوامل المتقدمة

| الجملة | عامل العرض | عامل الارتفاع | التعديل |
|--------|------------|---------------|---------|
| الطول = العرض زائد N | 1 | 0 | +N سم |
| الطول = العرض ناقص N | 1 | 0 | −N سم |
| الطول = الارتفاع زائد N | 0 | 1 | +N سم |
| الطول = الارتفاع ناقص N | 0 | 1 | −N سم |

لو العوامل ليست (1 و 0) أو (0 و 1)، تظهر «معادلة مخصّصة — استخدم المتقدم».

### 5.3 الوضع المتقدم

| الحقل | المعنى | تأثير مباشر |
|--------|--------|-------------|
| **عامل العرض** | كم مرة نضرب العرض الفعّال | 1 = كامل العرض؛ 0 = لا يدخل العرض؛ 0.5 = نصف… |
| **عامل الارتفاع** | كم مرة نضرب الارتفاع | نفس الفكرة للارتفاع |
| **التعديل (سم)** | ثابت يُضاف أو يُطرح بعد الضرب | خلوص، زيادة لحام، خصم زاوية… |
| **تقسيم عرض الضلفة** | هل نستخدم عرض الضلفة بدل العرض الكلي؟ | مهم للضلف والسحاب والزجاج أحيانًا |

يمكنك صنع معادلات مركّبة، مثل: نصف العرض + كامل الارتفاع + تعديل (نادر لكنه مدعوم).

## 6. رسوم: أين تقع القطع على الشباك؟

### 6.1 الإطار (Frame)

```
        ┌──────── Frame top (علوي) ────────┐
        │                                  │
 Frame  │                                  │  Frame
 jamb   │         فتحة الشباك              │  jamb
(قائم)  │                                  │ (قائم)
        │                                  │
        └──────── Frame bottom (سفلي) ─────┘

        ←──────────── العرض W ────────────→
        ↑                                  ↑
      الارتفاع H                        الارتفاع H
```

- **علوي / سفلي:** عادة الطول = العرض، الكمية 1 لكل واحد.
- **قائم الإطار:** عادة الطول = الارتفاع، الكمية 2 (يمين ويسار).

### 6.2 الضلفة (Sash)

```
        ┌──── Sash rail (عارضة أفقية) ────┐
        │                                   │
 Sash   │                                   │  Sash
 stile  │                                   │  stile
(قائم)  │                                   │ (قائم)
        │                                   │
        └──── Sash rail (عارضة أفقية) ────┘
```

- **قائم الضلفة (stile):** غالبًا من **الارتفاع ناقص** خلوص (مثل 4 سم)، كمية 2.
- **عارضة الضلفة (rail):** غالبًا من **العرض ناقص** خلوص، كمية 2.

الخلوص (مثل 4 سم) يعني: الضلفة أصغر من فتحة الإطار عشان تدخل وتتحرك.

## 7. أمثلة رقمية كاملة

نأخذ نفس أرقام الشاشة الشائعة: **عرض تجريبي = 100 سم، ارتفاع = 120 سم**.

### مثال أ — إطار علوي

- الطول = العرض زائد 0 سم  
- الكمية = 1  

```
الطول = 100 + 0 = 100 سم × 1 قطعة
```

### مثال ب — قائم الضلفة

- الطول = الارتفاع ناقص 4 سم  
- الكمية = 2  

```
الطول = 120 − 4 = 116 سم × 2 قطعة
```

### مثال ج — عارضة الضلفة

- الطول = العرض ناقص 4 سم  
- الكمية = 2  

```
الطول = 100 − 4 = 96 سم × 2 قطعة
```

### مثال د — تقسيم عرض الضلفة (سحاب)

افترض:

- عرض الفتحة W = 200 سم  
- عدد الضلف = 2  
- التداخل = 2.5 سم  
- قطعة عارضة ضلفة مع **تقسيم عرض الضلفة مفعّل**، عامل عرض = 1، تعديل = 0  

```
العرض الفعّال = (200 ÷ 2) + 2.5 = 100 + 2.5 = 102.5 سم
الطول = 1 × 102.5 + 0 × الارتفاع + 0 = 102.5 سم
```

لو أطفأت التقسيم لنفس القطعة:

```
الطول = 1 × 200 = 200 سم   ← طول على العرض الكامل (مناسب أكثر لإطار علوي/سفلي)
```

### مثال هـ — عاملان معًا (معادلة مخصّصة)

عامل عرض = 1، عامل ارتفاع = 0.5، تعديل = −2 سم، بدون تقسيم، W=100، H=120:

```
الطول = 1×100 + 0.5×120 + (−2) = 100 + 60 − 2 = 158 سم
```

استخدم هذا فقط لو عندك سبب ورشة واضح؛ للجمل البسيطة اكتفِ بالعرض أو الارتفاع وحدهما.

## 8. فتحات الزجاج

لكل فتحة زجاج:

| الحقل | الغرض |
|--------|--------|
| **الاسم** | تمييز الفتحة (رئيسي، جانبي…) |
| **عدد الألواح** | كم لوح زجاج في هذه الفتحة |
| **عرض الزجاج** | جملة مثل قطع الألومنيوم (من العرض/الارتفاع ± سم) |
| **ارتفاع الزجاج** | نفس الأسلوب لمحور الارتفاع |
| **مطلوب** | هل لازم يختار المستخدم زجاج في المشروع؟ |
| **متقدم** | عوامل عرض/ارتفاع منفصلة لـ W وللـ H، وتعديل لكل محور |
| **تقسيم عرض الضلفة** | نفس فكرة العرض الفعّال للضلف |

المساحة التقريبية للمتر المربع:

```
المساحة (م²) ≈ (عرض الزجاج مم × ارتفاع الزجاج مم) ÷ 1_000_000
ثم تُضرب في عدد الألواح وكمية العنصر في المشروع
```

الزجاج **لا يظهر** في قائمة «جرّب المقاس» الحالية؛ يظهر أثره عند حساب المشروع والتكلفة.

## 9. الإكسسوارات

لا توجد معادلة طول هنا — فقط **كمية**.

| قاعدة الكمية | المعنى | مثال |
|--------------|--------|------|
| **لكل منتج** | الكمية × عدد الوحدات في المشروع | مقبض واحد لكل شباك |
| **لكل ضلفة** | الكمية × عدد الضلف × عدد الوحدات | عجلتان لكل ضلفة × 2 ضلفة = 4 |

| الحقل | الغرض |
|--------|--------|
| الاسم | تسمية السطر |
| الكمية | الرقم الأساسي قبل القاعدة |
| إكسسوار افتراضي | يربط بكتالوج الإكسسوارات في الموارد |

## 10. من الوصفة إلى المشروع وخطط القص

1. تعدّل وتحفظ الوصفة هنا.  
2. في المشروع تختار الموديل وتدخل عرض وارتفاع العميل.  
3. «احسب» يولّد أطوال الألومنيوم والزجاج وكميات الإكسسوار.  
4. الأطوال تدخل خطط القص والشراء.

لو غيّرت الوصفة بعد مشاريع قديمة، المشاريع المحسوبة سابقًا قد تحتفظ بلقطة قديمة حسب تصميم النظام — راجع المشروع وأعد الحساب عند اللزوم.

## 11. أخطاء شائعة وكيف تتجنبها

| المشكلة | السبب | الحل |
|---------|--------|------|
| المعاينة ما اتغيرتش | لم تحفظ القطعة أو الموديل | احفظ ثم غيّر العرض التجريبي |
| عدد الضلف في المعاينة قديم | المعاينة من القيم المحفوظة | احفظ بطاقة الموديل أولًا |
| طول صفر أو سالب | خصم أكبر من المقاس | قلّل «ناقص» أو راجع العوامل |
| إطار علوي بقياس ضلفة | تفعيل تقسيم بالخطأ على الإطار | أطفي التقسيم لإطار علوي/سفلي |
| خلط سم و مم | النظام يخزّن مم ويعرض سم | تذكّر: 4 سم = 40 مم داخليًا |
| نسيت ألومنيوم افتراضي | الحساب قد يطلب اختيار الخامة لاحقًا | اربط بروفايل من الموارد |

## 12. لو سيّبت مدخل فاضي — إيه اللي يحصل؟

ليس كل فراغ يرفض الحفظ: بعض الحقول **تُرفض فورًا**، وبعضها **يُقبل لكن الحساب يفترض قيمة افتراضية**، وبعضها يمرّ في الوصفة ثم **يوقف المشروع** لاحقًا.

| المدخل / الخيار | لو فاضي أو غير مختار | عند الحفظ | عند الشغل والحساب | أثر الشغل |
|-----------------|----------------------|-----------|-------------------|-----------|
| **اسم** الموديل أو القطعة أو فتحة الزجاج أو الإكسسوار | نص فارغ | **مرفوض** | — | ما تقدرش تكمّل حفظ الوصفة؛ صحّح الاسم |
| **عدد الضلف** | فارغ أو ≤ 0 | مقبول (فارغ يُحفظ كقيمة فارغة) | يُعامل كـ **1** | تقسيم عرض الضلفة وإكسسوار «لكل ضلفة» كأن الوحدة **ضلفة واحدة** — كميات وأنصاف عرض غلط لو الشباك سحاب بضلفتين |
| **التداخل** | فارغ | مقبول (`null`) | يُحسب كـ **0** | مفيش زيادة على عرض الضلفة عند التقسيم؛ أطوال الضلف أقصر من الواقع لو عندك تراكب |
| **كمية** القطعة / عدد الألواح / كمية الإكسسوار | فارغ أو ≤ 0 | **مرفوض** | — | لازم رقم أكبر من صفر قبل الحفظ |
| **رقم زائد/ناقص** في جملة الطول | فاضي | يُحفظ كـ **0** | الطول = العرض أو الارتفاع بدون خلوص | إطار/ضلفة بدون خصم ورشة؛ المقاس هيطلع أكبر من اللي بتقطعه عادة |
| **ألومنيوم افتراضي** | شرطة (`—`) | مقبول | لازم تختار خامة لكل قطعة في المشروع وإلا **فشل الحساب** | توقف التكلفة وخطط القص لحد ما تختار البروفايل |
| **إكسسوار افتراضي** | شرطة (`—`) | مقبول | الكمية ما تدخلش الفاتورة إلا بعد اختيار إكسسوار في المشروع | نقص مقابض/عجلات من التكلفة والكميات |
| **زجاج «مطلوب»** | مفعّل ومفيش اختيار زجاج في المشروع | الوصفة تمام | خطأ: فتحة زجاج مطلوبة ناقصة | المشروع **ما يكتملش** الحساب |
| **زجاج غير مطلوب** | مطفي ومفيش اختيار زجاج | الوصفة تمام | الفتحة **تُتخطى** | لا زجاج ولا تكلفة لهذه الفتحة — مناسب لو الفتحة اختيارية |
| **تقسيم عرض الضلفة** | مطفي / مش متعلّم | مقبول | العرض الفعّال = **العرض الكلي** | سلوك صحيح للإطار؛ لو نسيته على عارضة ضلفة السحاب الطول هيطلع بعرض الشباك كله مش الضلفة |
| **عامل العرض وعامل الارتفاع = 0** معًا | معادلة تعطي طول ≤ 0 | قد يُحفظ | **فشل الحساب** (الطول لازم > 0) | ما ينفعش تكمّل قص/تكلفة لحد ما تصلّح المعادلة |
| **نشط** | مطفي | مقبول | الموديل مش متاح عمليًا للاستخدام اليومي | الورشة مش هتلاقي الموديل بسهولة في المشاريع |

**خلاصة سريعة:** الأسماء والكميات لازم تتملّى؛ عدد الضلف والتداخل الفاضيين يتحوّلوا لصمت حسابي (1 و 0)؛ الخامات والإكسسوارات الافتراضية الفاضية تؤجّل المشكلة للمشروع؛ الزجاج المطلوب الفاضي يوقف الحساب.

## 13. جدول مرجعي سريع — كل مدخل وتأثيره

| المدخل | أين؟ | يؤثر على الطول؟ | ملاحظة |
|--------|------|------------------|--------|
| اسم الموديل | الموديل | لا | عرض فقط؛ **فارغ = رفض الحفظ** (انظر §12) |
| عدد الضلف | الموديل | نعم إن وُجد تقسيم ضلفة / إكسسوار لكل ضلفة | فارغ عند الحساب = 1 |
| التداخل | الموديل | نعم مع التقسيم | فارغ عند الحساب = 0 |
| نشط | الموديل | لا مباشرة | مطفي = غير متاح عمليًا |
| عرض/ارتفاع تجريبي | المعاينة | للعرض فقط | لا يُحفظ كوصفة |
| اسم القطعة | القطع | لا | فارغ = رفض الحفظ |
| محور عرض/ارتفاع | القطع | نعم | يحدّد الاتجاه |
| زائد/ناقص + N | القطع | نعم | N فاضي = 0 |
| الكمية | القطع | كمية لا طول | ≤ 0 = رفض الحفظ |
| ألومنيوم افتراضي | القطع | خامة لا طول | فاضي = اختيار لاحق في المشروع أو فشل |
| عامل العرض/الارتفاع | متقدم | نعم | الاثنان صفر → طول خطر / فشل |
| التعديل (سم) | متقدم | نعم | ثابت |
| تقسيم عرض الضلفة | متقدم | نعم على العرض الفعّال | مطفي = عرض كلي |
| عرض/ارتفاع الزجاج | الزجاج | مقاس الزجاج | مساحة وتكلفة |
| عدد الألواح | الزجاج | كمية الزجاج | ≤ 0 = رفض الحفظ |
| مطلوب | الزجاج | إلزام في المشروع | مطلوب + بدون اختيار = فشل |
| قاعدة كمية الإكسسوار | إكسسوار | كمية فقط | منتج أو ضلفة؛ افتراضي فاضي يؤجّل للمشروع |

## 14. خطوات عملية مقترحة لضبط وصفة ورشتك

1. اختر موديلًا (مثل قلاب / سحاب).  
2. اضبط عدد الضلف والتداخل واحفظ (متسيبش عدد الضلف فاضي لو السحاب بضلفتين).  
3. لكل قطعة إطار: جملة بسيطة بدون تقسيم ضلفة.  
4. لقطع الضلف: خلوص ناقص مناسب + كمية صحيحة؛ فعّل التقسيم إن لزم.  
5. املأ «جرّب المقاس» بمقاس شائع عندك وطابق النتيجة مع حسابك اليدوي.  
6. اضبط الزجاج والإكسسوارات (ولو الزجاج مطلوب، جرّب مشروعًا وتأكد إن الاختيار موجود).  
7. جرّب عنصرًا في مشروع حقيقي ثم خطّة قص.

## 15. خلاصة المعادلة في سطر واحد

> **الطول = (جزء من العرض الفعّال) + (جزء من الارتفاع) + تعديل ثابت.**  
> **العرض الفعّال إما العرض كله، أو عرض الضلفة + التداخل.**

بهذا تفهم كل قائمة منسدلة وكل رقم في الصفحة — وما فيش حاجة متروكة للصدفة.
